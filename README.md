# CommonsLang_Rust

A dk package that builds Rust static libraries inside a dk build, with the official
Rust toolchain (1.99.1) and cargo running offline against a locked workspace.
`dk.u` documents the rules and how to use them.

## Layout

- `etc/dk/v/CommonsLang_Rust/Toolchain.Bundle.values.jsonc`, `Host.values.lua`,
  `Std.values.lua`: the toolchain, generated by `maintenance/generate-toolchain.py`.
- `etc/dk/v/CommonsLang_Rust/Cargo.values.lua`: `F_StaticLib`, the build rule.
- `etc/dk/v/CommonsLang_Rust/CargoLock.values.lua`: the `Bundle` dialog, which turns a
  `Cargo.lock` into a crates bundle.
- `assets/cargo/build-staticlib.sh` (macOS, Linux) and `build-staticlib.ps1`
  (Windows): the build scripts `F_StaticLib` runs.
- `assets/fixture/ring`: a workspace whose library calls ring, built by every
  `dist/*.u` script, with its crates bundle in
  `etc/dk/v/CommonsLang_Rust/Fixture.Crates.Bundle.values.jsonc`.

## Moving to a new Rust version

```sh
python3 -I maintenance/generate-toolchain.py <version> <download-dir>
```

Then change `1.99.1` in `Cargo.values.lua` (`rust`), `dist/*.u`, `dk.u` and this file,
and bump the patch of every module whose body changed.

## Testing a slot locally

Copy a `dist/<ABI>.u` with `${RUNTIME}` replaced by a folder, then run it as a unified
test. For a cross slot, pass both ABIs:

```sh
./dk0 --execution-abi Darwin_arm64 --target-abi Darwin_x86_64 \
  -I etc/dk/v --trust-local-package CommonsLang_Rust test target/local-x86.u
```
